# FIXRW

This repository contains the artifact for our paper:

> **Fix or Fail? Testing Fixes for Concurrency Bugs via Read-Write-Dependency-Guided Schedule Exploration**

## Contents

- **`baselines/`** — Implementations of the baseline tools used in our evaluation.
- **`dataset/`** — The concurrency fix testing dataset constructed for this work. 
- **`FIXRW/`** — Coming soon. The source code of FIXRW is currently pending patent licensing discussions with a commercial partner and is therefore not yet publicly available. If the code can be released in the future, we will make it publicly available in this repository.
